Create & Query a Students Table
Create a database named school and select it. Create a table students, insert the given rows, then display the students who scored above 60.
Time Left 04:32

Input Format

  • Database: school
  • Table: students (id INTEGER PRIMARY KEY, name TEXT, marks INTEGER)
  • Rows: (1, 'Asha', 78), (2, 'Ravi', 55), (3, 'Mira', 91)

Output Format

  • Show id, name and marks of students with marks > 60.
  • Order the result by marks in descending order.

Example

Input
Database: school
Table: students (id, name, marks)
Rows: (1, Asha, 78), (2, Ravi, 55), (3, Mira, 91)
Output
id | name | marks
3 | Mira | 91
1 | Asha | 78
